## 3. 象徴

### 3.1 中核象徴(4語)

1. **決断**
2. **浄化**
3. **終わりと始まりの境**
4. **凛とした静けさ**

### 3.2 派生象徴

- 秋の風(澄んだ冷気)
- 薄(すすき)、芒の穂
- 月光(直接の月ではなく、地に届いた光)
- 白い息(息が白く見える夜の冷気)
- 古い剣の鞘(意匠としてのみ。武器そのものは出さない)

### 3.3 採用しない象徴

- 戦闘・武具の主役化(武勇伝風になりNG)
- 雪のクリスマス的演出(西洋記号化を避ける)
- 純白の華やかドレス感(コスプレ化)

---

## 4. ビジュアルキー要素

### 4.1 必須要素

| # | 要素 | 詳細 |
| --- | --- | --- |
| 1 | **soft cream の被毛** | 純白(`#FFFFFF`)ではなく、少し温度を含んだクリーム |
| 2 | **charcoal の縞** | 強い黒ではなく、墨色のかすれた縞。本数を増やしすぎない |
| 3 | **凛とした表情** | 半眼または遠景。攻撃性なし、笑みなし |

### 4.2 強推奨要素

| # | 要素 | 詳細 |
| --- | --- | --- |
| 4 | **薄の野** | 風になびく薄が画面の中景〜遠景に存在 |
| 5 | **月光の余韻** | 月そのものは描かず、地面・草・毛皮に届いた光で示す |
| 6 | **muted gold の小粒** | 月光の粒子として、秋の空気にうっすら散る |

### 4.3 任意要素

- 古い社の石段(主役にしない、暗示的に)
- 苔・落ち葉(色味を抑えて)
- 細い水路(月の反射を indigo で乗せる)

### 4.4 パレット紐づけ

| 要素 | 主色 | 副色 |
| --- | --- | --- |
| 被毛 | soft cream | muted gold(光の当たる側) |
| 縞 | charcoal | — |
| 薄 | soft cream | charcoal(穂先の影) |
| 光粒子 | muted gold | — |
| 影 | charcoal | indigo(夜気のごく一部) |

## 5. 性格・人格(三語)

- **凛**(ぴんと張った)
- **潔**(きよい)
- **気高い**(おもねらない)

> 白虎は「主張せずに、選択を済ませている」存在。冷たくはなく、静かに距離を保つ。

## 6. NG表現リスト(白虎個別)

`world-view.md` §7 共通 NG に加え、白虎では特に:

| カテゴリ | 白虎では特に避ける |
| --- | --- |
| 攻撃性 | 牙剥き、唸り、戦闘ポーズ、武具の主役化 |
| 派手さ | 純白の輝き(蛍光的に光る毛皮)、虹色のオーラ |
| 西洋化 | アヴァロン的・ファンタジー騎士的演出、十字架モチーフ |
| コスプレ化 | 鎧・着物を「装着」した擬人化白虎 |
| 既存IP想起 | 既存作品の有名な白虎/タイガーキャラデザインへの寄せ |

## 8. 監修チェック項目(白虎概要レベル)

### 8.1 同定チェック

- [ ] 被毛が純白ではなく **soft cream**
- [ ] 縞が純黒ではなく **charcoal の墨かすれ**
- [ ] 表情が凛(攻撃的でも笑顔でもない)
- [ ] **薄 / 月光の余韻 / muted gold 粒子** のいずれか1要素以上ある

### 8.2 世界観チェック

- [ ] パレット4色から逸脱していない
- [ ] 水彩・和紙・墨線の媒質感
- [ ] 30〜40代女性誌の表紙感
- [ ] 構図見切れなし

### 8.3 NG混入チェック

- [ ] サイバーパンク要素なし
- [ ] 血・暴力なし
- [ ] コミカル・SD化なし
- [ ] 武具の主役化なし
- [ ] 既存IP想起意匠なし
