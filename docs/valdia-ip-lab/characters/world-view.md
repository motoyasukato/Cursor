## 1. コンセプト

### 1.1 一行コンセプト

> **「水彩で描かれた、和モダン × エディトリアルの神獣図鑑」**

### 1.2 トーン

- **静謐**(攻撃的・誇張的ではない)
- **知的**(コミカル・キャラクターっぽい記号化を避ける)
- **希望**(陰鬱・退廃・血生臭さを避ける)
- **品位**(キッチュ・ゲーム的記号化を避ける)

### 1.3 想定読者・想定購買層

- 30〜40代女性
- 雑誌で言うと「クロワッサン」「anan」表紙感の知的・落ち着き・暮らしの上質
- 一人暮らしの本棚・カフェ・小さなギャラリー・上質なステーショナリー店に置いて違和感がないこと

### 1.4 採用しない領域(明示禁止)

| 領域 | 禁止理由 |
| --- | --- |
| サイバーパンク要素 | 世界観と齟齬。発光ネオン・回路紋・メカ装飾・ホログラムは **完全排除** |
| ファンタジーゲーム的記号 | 装備品・武器・属性アイコン・ステータスバー風表現は不採用 |
| ホラー・グロ要素 | 血、傷、欠損、不気味な笑い、過度な暗黒は不採用 |
| コミカル / SD化 | デフォルメ・ちびキャラ・誇張表情は不採用(別ライン展開時に再検討) |
| 西洋ドラゴン的記号 | 翼の強調・炎・宝石コレクションは不採用(神獣は東洋の系譜) |
| 過度なテック・宇宙要素 | 衛星・ロボ・SF的舞台は不採用 |
| キャラクター名・ロゴの画面内描写 | プロンプトで紛れ込ませない(指示書4 と整合) |

## 2. カラーパレット(逸脱禁止)

> 4色を **基本パレット** とし、これ以外の色を主役に据えない。差し色・反射光のみ厳格な範囲で許容。

### 2.1 基本4色

| 役割 | 色名 | 想定HEX(目安) | 用途 |
| --- | --- | --- | --- |
| Hue 1 | **muted gold** | `#B89968` 前後 | 光・粒子・象徴・装飾線 |
| Hue 2 | **indigo** | `#2E4A6B`〜`#1F3550` 前後 | 鱗・水・夜・深奥 |
| Base | **soft cream** | `#F2EBDC` 前後 | 紙・霧・余白・空気 |
| Anchor | **charcoal** | `#2A2A2A` 前後 | 線・影・縞・墨 |

> HEX は目安。実装時は紙質・印刷・画面の3媒体で **同等の印象** が得られるよう、各キャラ書とプロンプトで微調整可。ただし「鮮やかすぎる」「彩度の高い」方向には倒さない。

### 2.2 差し色(限定許容)

| 場面 | 許容色 | 上限 |
| --- | --- | --- |
| 朝の光・夕景の境 | 淡い陽光のオフホワイト寄り gold | 画面全体の 5% 以内 |
| 古樹・草・植物の萌え色 | くすんだ抹茶/苔色 | 全体の 5% 以内、彩度低め |
| 水面のハイライト | indigo の明度高い派生 | 反射のみ |

### 2.3 禁止色(主役・面積で使わない)

- 鮮やかな赤・朱・紅(朱雀を除外している理由とも整合。出血・燃焼・派手さの記号となる)
- 蛍光色全般、ネオン色全般
- 高彩度のマゼンタ・ターコイズ・ライム
- 純黒(`#000000`)・純白(`#FFFFFF`)— charcoal / soft cream を使う

## 3. 媒質感(マテリアル)

### 3.1 基準テクスチャ

- **水彩(透明水彩)**: にじみ・グラデーション・余白を活かす
- **和紙**: 繊維感、薄い斑(ふ)、柔らかい縁
- **墨線**: 細く、抑制的に。輪郭を描き切らず、抜きを残す
- **エディトリアルの紙質**: 高級雑誌の表紙紙のような光のなじみ

### 3.2 採用しない質感

- 写実3DCGのリアル鱗・リアル毛皮(写真のような肌・毛のクローズアップは不採用)
- ビニール / プラスチック光沢
- アニメ風のベタ塗り(セル画調)
- ゲーム的なエフェクト(きらきら過剰、エナジー過剰)

### 3.3 ハイライトと粒子

- **金色の光粒子**(蒼龍以外でも共通モチーフとして許容)は muted gold で描く
- 粒子は「散らす」のであって「光線にしない」(光線・ビーム表現は禁止)
- 霧・湯気・かすみは soft cream の延長として描く

## 4. 構図とアスペクト

### 4.1 標準アスペクト

| 比率 | 主用途 |
| --- | --- |
| **9:16(縦)** | アクスタ、ポスター、タペストリー、雑誌表紙 |
| **16:9(横)** | バナー、Web ヘッダー、横長アート |
| **1:1(正方形)** | SNS、ポストカード(正方形版)、ジャケット |

### 4.2 構図原則

- **見切れ禁止**: 神獣の「体」「首」「尾」が画面端で唐突に切れない(部分意匠としての首から上は別途)
- **重心の置き方**: 縦長は上 1/3 に光源、下 2/3 に神獣の存在感
- **余白**: 雑誌表紙感を出すため、紙面上部または右側に「タイトルが置けるくらいの余白」を残す構図を1パターン用意
- **視線**: 神獣はカメラを正視せず、斜め上または遠景を見る(挑発的・対峙的にならない)

### 4.3 採用しない構図

- 真正面・絶対対称(神社装飾的になり、雑誌感から離れる)
- 戦闘ポーズ・睨み・牙剥き
- 過剰なローアングル(威圧・スーパーヒーロー記号)
- 手前への急激なパース(漫画的アクション)

## 5. 時代感

- **和モダン**: 江戸・明治の意匠を素材として持ちながら、現代の編集デザインに昇華
- 古典再演ではなく **現代の知的趣味** として神獣を捉える
- 着物・伝統文様は許容するが「コスプレ」化させない(キャラに装着しない)
