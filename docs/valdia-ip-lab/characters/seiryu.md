## 2. 五行属性

| 項目 | 値 |
| --- | --- |
| 干 | **甲**(きのえ) |
| 五行 | **木陽** |
| 季節 | 春 |
| 方位 | 東 |
| 五色 | 青(本ラインでは indigo として扱う) |
| 関連する徳 | 仁 |

### 2.1 五行的な性質の取扱い

- **木陽** は「上に伸びる力・始まる力」。蒼龍はこの「上昇」のエネルギーを **静かに** 体現する。
- 「派手に伸びる」のではなく「気がつくと、いつのまにか高い場所まで来ていた」感覚で表現する。
- 季節は春だが、桜・花吹雪のような分かりやすい春記号には依存しない(コミカル化・記号化を避けるため)。

## 3. 象徴

### 3.1 中核象徴(逸脱禁止の4語)

1. **成長**
2. **上昇**
3. **運命の始動**
4. **開運**

### 3.2 派生象徴(プロンプト・監修で参照可)

- 朝(夜明け、霧の晴れる瞬間)
- 古樹(根を張り、上に伸びるもの)
- 朝霧(視界が開けていく直前の静けさ)
- 金色の光粒子(運命が動き出す比喩)
- 川の上流(始まりの水)

### 3.3 採用しない象徴

- 雷・嵐(攻撃的・恐怖の方向)
- 火炎(朱雀領域。蒼龍では不採用)
- 戦勝・武運(神社の戦勝祈願系の記号)
- 富・拝金(「開運」を「金運の派手な表現」に堕とさない)

## 4. ビジュアルキー要素(プロンプト化前提の素材)

> ここに挙げた要素を **組み合わせる** ことで蒼龍は同定される。1要素だけでも、全部詰め込みでもなく、後述「必須/推奨/任意」の階層で組む。

### 4.1 必須要素(これがないと蒼龍に見えない)

| # | 要素 | 詳細 |
| --- | --- | --- |
| 1 | **蒼い鱗** | indigo 基調、muted gold のハイライトのみ。鮮やかな青は使わない。鱗は写実的な硬質感ではなく、**水彩のにじみ** で描かれた柔らかい鱗 |
| 2 | **東洋龍の体型** | 細長く、しなやか、四肢は細く、髭(ひげ)、鹿角風の角、鯉のような背びれ。西洋ドラゴンの翼・宝石コレクション・口から炎は不採用 |
| 3 | **静謐な表情** | 半眼または遠景を見る目。攻撃性・笑い・コミカル誇張は不採用 |

### 4.2 強推奨要素(画面構成の基本骨格)

| # | 要素 | 詳細 |
| --- | --- | --- |
| 4 | **古樹に絡む** | 苔むした老樹に体を巻きつける、または並ぶ。古樹は構図の縦軸を作る存在 |
| 5 | **朝の霧** | soft cream の柔らかい霧。視界が開けてくる瞬間の質感 |
| 6 | **金色の光粒子** | muted gold の細かい粒子。霧の中に散る、神獣の周辺に漂う。光線・ビームではなく **粒** で表現 |

### 4.3 任意要素(構図のバリエーションに応じて選択)

- 川の上流(浅瀬・透明・indigo の反射)
- 苔・羊歯類(彩度低めの抹茶色、ごく控えめに)
- 朝陽(直接の太陽は描かず、光のなじみで示唆)
- 和紙のテクスチャ(背景レイヤーとして)
- 古い書(蒼龍が古い書物・絵巻の中から立ち上がる演出のときのみ)

### 4.4 各要素のパレット紐づけ(再掲)

| 要素 | 主色 | 副色 |
| --- | --- | --- |
| 鱗 | indigo | muted gold(ハイライトのみ) |
| 古樹 | charcoal(幹)| 抹茶/苔(極控えめ) |
| 霧 | soft cream | — |
| 光粒子 | muted gold | — |
| 水 | indigo | soft cream(反射) |

## 5. 性格・人格

### 5.1 三語規定(逸脱禁止)

- **静謐**(しずか)
- **知的**(かしこい)
- **希望**(明るい兆し)

### 5.2 性格の表現方針

- 表情で表すより、**佇まい・距離感・視線の角度** で表す
- 「優しい」「強い」「誇り高い」など複数の形容詞を盛らず、**3語で十分** とする(キャラの輪郭がぼやけるのを防ぐ)
- 静謐 = 沈黙の重さ。知的 = 観察する側にいる。希望 = 視線がやや上を向く。

### 5.3 採用しない人格表現

- 怒り、悲しみ、嫉妬、戦意などの強い情動
- おどけ、いたずら、皮肉、コミカルな仕草
- 主人(人間)に従属するペット感(蒼龍は対等以上の存在)

> `world-view.md` §7 の共通 NG に加え、蒼龍固有で特に避けるもの:

## 7. 商品展開適性

### 7.1 第1期商品(蒼龍で展開する候補)

| 商品 | 適性 | 推奨アスペクト・サイズ | 備考 |
| --- | --- | --- | --- |
| **アクリルスタンド(アクスタ)** | ◎ | 9:16 縦 | 蒼龍の「上昇」感が縦長と相性良い。背景透過版を別途用意 |
| **ポストカード** | ◎ | 9:16 縦 / 1:1 / 16:9 横 各1種 | 雑誌表紙感の余白構図を活用。販売ロット小さく試せる |
| **タペストリー** | ◎ | 9:16 縦(B1・B2) | 古樹に絡む構図が映える。インテリア需要 |
| **クリアファイル** | ○ | A4 縦 | 9:16 構図のクロップで対応可 |
| **ブックマーク(しおり)** | ○ | 縦長極細 | 古樹+蒼龍の縦軸を活かせる |
| **ジクレー版画(限定)** | ○ | 9:16 / 1:1 | 高単価ラインのテスト用 |

### 7.2 第1期で扱わないもの(理由付き)

| 商品 | 不採用理由 |
| --- | --- |
| マグカップ | 円筒展開で水彩感が崩れやすい。後期で改めて検討 |
| Tシャツ・アパレル | コスト・在庫リスク高、第1期で扱うと撤退余力を食う |
| ぬいぐるみ | デフォルメが必須。コミカル化 NG と衝突 |
| ゲーム的グッズ(ステータスカード、戦闘風) | 世界観 NG |
| 香水・コスメ | OEM 体制が別。Phase 0 のスコープ外 |

### 7.3 商品化時の必須確認

- VALDIA 工場で実際に製造可能なフォーマットか(発注先と仕様整合)
- パレット 4 色が印刷で再現できる(色校正)
- 9:16 / 16:9 / 1:1 の元画像が監修通っている
- 文字・ロゴ・著作物想起要素が混入していない(指示書4 の権利安全チェック)

## 8. 監修チェック項目(蒼龍個別)

> 指示書4「監修基準書」と内容が重なる部分は、本書では **キャラ同定の観点に絞って** 列挙する。生成物の客観評価詳細は指示書4を参照。

### 8.1 同定チェック(これに通らない = 蒼龍と呼べない)

- [ ] **東洋龍の体型**(細長くしなやか、髭、鹿角風の角)である
- [ ] **蒼い鱗が indigo 基調** であり、鮮やかな青ではない
- [ ] **muted gold のハイライト** のみで、虹色・ネオン色のハイライトがない
- [ ] **静謐な表情**(攻撃的でない、コミカルでない)である
- [ ] **古樹 / 朝霧 / 金色粒子** のいずれか1要素以上が画面に存在する
- [ ] 翼・口から火・宝石コレクション など **西洋ドラゴン記号** がない

### 8.2 世界観チェック

- [ ] パレット4色から **逸脱していない**(差し色も §2 の限度内)
- [ ] **水彩・和紙・墨線** の媒質感が出ている(写真風・3D風・セル画風になっていない)
- [ ] 構図に **見切れ** がない(蒼龍の体・首・尾が画面端で唐突に切れていない)
- [ ] **30〜40代女性誌の表紙感** がある(キャラっぽい記号化・ゲーム風になっていない)

### 8.3 NG混入チェック

- [ ] サイバーパンク要素なし(回路・ネオン・ホログラム・メカ)
- [ ] 血・傷・暴力的要素なし
- [ ] コミカル・SD化なし
- [ ] 文字・ロゴ・既存IP想起意匠の混入なし

### 8.4 商品化観点チェック

- [ ] 9:16 / 16:9 / 1:1 のうち **本商品で必要なアスペクト** が用意できる構図
- [ ] アクスタ用に **背景透過化** に耐える主体ライン(背景と完全に溶けていない)
- [ ] 印刷時に muted gold が「鈍く沈んだ金色」として再現できる(蛍光黄色化しない)
- [ ] 監修3段(world-view → seiryu書 → 指示書4)を通している
