## 3. 象徴

### 3.1 中核象徴(4語)

1. **守護**
2. **継承**
3. **記憶**
4. **沈黙の重さ**

### 3.2 派生象徴

- 雪の沈黙(積もった雪、音が吸い込まれる空気)
- 古い甲羅・古い書物(知の蓄積)
- 深い水・湖の底(光が届かない深奥)
- 蛇のしなやかさ(亀と蛇の合体表現)
- 古い石碑・墨字(意匠として、文字は読ませない)

### 3.3 採用しない象徴

- 死・墓所の生々しい描写(陰鬱化を避ける)
- 北極・極地のリアル氷山(西洋自然写真化を避ける)
- 怪奇・ホラー要素

## 4. ビジュアルキー要素

### 4.1 必須要素

| # | 要素 | 詳細 |
| --- | --- | --- |
| 1 | **亀と蛇の合体** | 古典的な玄武像に従う。亀の甲羅に蛇が巻きつく/絡む構図 |
| 2 | **甲羅の意匠** | 甲羅は indigo 深部 + charcoal。微かに古い文字風の紋様(具体文字は描かない) |
| 3 | **沈黙の表情** | 半眼、視線は遠い時間 / 過去 を見ている雰囲気 |

### 4.2 強推奨要素

| # | 要素 | 詳細 |
| --- | --- | --- |
| 4 | **雪気・冷気** | soft cream の冷たい空気、息が白く見える質感 |
| 5 | **muted gold の沈み光** | 微かに光る粒子。蒼龍より控えめ |
| 6 | **深い水面** | indigo 深部の水。波立たず、鏡のような静けさ |

### 4.3 任意要素

- 古樹の根(雪に埋もれた)
- 苔むした石(冬枯れの色味で)
- 古い社・石灯籠(主役にしない、遠景)

### 4.4 パレット紐づけ

| 要素 | 主色 | 副色 |
| --- | --- | --- |
| 甲羅 | indigo 深部 | charcoal(紋様) |
| 蛇の鱗 | charcoal | indigo(ハイライト) |
| 雪気 | soft cream | — |
| 水面 | indigo 深部 | soft cream(微かな反射) |
| 光粒子 | muted gold(控えめ)| — |

## 5. 性格・人格(三語)

- **寡黙**(語らない)
- **深慮**(深く考える)
- **包容**(裁かず受ける)

> 玄武は「すべてを覚えている沈黙」。蒼龍の上昇感、白虎の決断感に対し、玄武は **時間そのものの存在感** を担う。

---

## 6. NG表現リスト(玄武個別)

`world-view.md` §7 共通 NG に加え、玄武では特に:

| カテゴリ | 玄武では特に避ける |
| --- | --- |
| 陰鬱化 | 死・墓所・骨・腐敗の直接描写。冷たく寂しいだけの画 |
| 怪奇化 | ホラー的演出、不気味な笑い、闇から伸びる手など |
| 過剰な暗さ | 純黒で塗りつぶす(charcoal までに留める)、月明かりすら無い真っ暗 |
| 西洋化 | リアル北極氷山、極地探検写真風 |
| コスプレ化 | 甲羅を装着した擬人化玄武 |
| 既存IP想起 | 既存作品の有名な玄武/亀キャラへの寄せ |

## 7. 商品展開適性

第1期(蒼龍)成功後の派生として、蒼龍・白虎と同フォーマットで揃える。

| 商品 | 適性 | 推奨アスペクト |
| --- | --- | --- |
| アクリルスタンド | ○ | 9:16 縦 |
| ポストカード | ◎ | 9:16 / 1:1 / 16:9 |
| タペストリー | ◎ | 9:16 縦(冬の落ち着きはタペ向き) |
| クリアファイル | ○ | A4 |

> 玄武は「動きが少ない」キャラのため、アクスタよりタペストリー・ポストカード適性が相対的に高い。詳細は派生展開フェーズで再評価。

## 8. 監修チェック項目(玄武概要レベル)

- [ ] **亀と蛇の合体** 表現が成立している
