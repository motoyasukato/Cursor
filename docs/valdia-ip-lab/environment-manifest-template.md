# Environment Manifest テンプレート

| 項目 | 内容 |
| --- | --- |
| 文書ID | VIL-W1-02b |
| バージョン | 0.1 (Draft) |
| 作成日 | 2026-05-11 |
| 用途 | ComfyUI 検証環境ごとの記録テンプレート |
| 保存先 | `docs/valdia-ip-lab/manifests/<検証ID>/environment-manifest.md` |
| 関連文書 | `comfyui-cloud-to-local-policy.md`(指示書2) |

> **使い方**:
> 1. 検証開始時に本テンプレートを `docs/valdia-ip-lab/manifests/<検証ID>/environment-manifest.md` にコピー
> 2. 「未記入」の項目を埋める
> 3. 検証終了時に `## 終了時記録` セクションを完成させる
> 4. クラウド検証は `environment_type: cloud`、ローカル検証は `environment_type: local` を選択
> 5. クラウド → ローカル移行検証時は **両方の manifest を作成** し、§13「移行差分」に差を記録
>
> **検証ID 形式**: `YYYYMMDD-XX`(例: `20260512-01`)。同日複数検証時は連番で `XX` を増やす。

## 16. データ管理チェックリスト(指示書1 §9)

### 16.1 環境構築時

- [ ] 永続ボリューム暗号化を確認した

- [ ] ComfyUI / custom_nodes を commit ピン留めした
- [ ] Docker image をタグ / digest で固定した
- [ ] プロンプト・seed ログ出力設定をした

### 16.2 検証終了時

- [ ] 保管対象生成物を VALDIA 側へ持ち出した
- [ ] 不要素材をクラウド側で削除した
- [ ] 永続ボリュームを削除し、削除証跡を保管した
- [ ] インスタンスを完全停止し、課金停止を確認した
- [ ] (顧客IP取扱時)削除証跡を顧客向け報告に添付できる形で保管した
